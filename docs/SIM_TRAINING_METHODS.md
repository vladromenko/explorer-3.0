# Подготовка симуляционного обучения: источники, решения, проверки

13 ноября 2026. Обучение по просьбе пользователя не запускалось. Ни внешний вид сцены, ни успешный scripted expert не доказывают качество ACT/PPO или перенос на железо.

## Принятые решения по документации и исследованиям

## Что уже измерено без обучения

- Для SO и ROS arm: по три полных исполнения геометрического учителя с удержанием кубика до раскрытия. Максимальное проникновение в номинальной сцене соответственно 0,403 и 0,221 мм, включая удар о дно коробки. Вариант seed7 с изменённой массой/трением проверяется тем же критерием.
- `tests/test_sim_variation.py`: воспроизводимость условий, восстановление состояния физики и параметров после другой расстановки, возврат к номинальной модели.
- Нормировка и сохранение PPO проверяются с **нулём шагов обучения**. Новые веса навыка не получены и не заявлены.
- Новая сцена SO на текущей нагрузке Homebrain: 1/2/4 последовательно обслуживаемых среды дают примерно 322/321/318 управляющих шагов в секунду суммарно, RSS процесса около 0,70/0,95/1,10 GB. Камера после прогрева около 2–5 мс. Это не GPU batch benchmark и не измерение training throughput. Файл `validation/corrective-a/laboratory/so101-resources.json`.

## Условия будущего запуска пользователем

Базовая сцена и вариант условий — отдельные явно выбранные условия эксперимента. Начать с пригодных успешных показов и проверенного тракта, затем сравнивать nominal/varied при одинаковых данных, числе обновлений и seed. Не менять одновременно геометрию, observation contract, reward и бюджет в одном сравнении. RGB политика не получает координаты кубика, фазу задачи или скрытые параметры симулятора.

Validation используется для выбора checkpoint; test — после фиксации модели, без подбора по его результату. Основной результат — success/failure по отпусканию/остановке, отдельно длительность, технические abort и доверительный интервал; loss только диагностический показатель. Сравнивать несколько seed обучения в согласованном конечном бюджете. До выполнения этих запусков улучшение навыка — гипотеза, не PASS.

Остаются отдельными незавершёнными частями A: раунды обученных политик в готовой общей сцене Fleet-DAgger, онлайн AutoIntervene-adapted, исследовательские серии на готовом индивидуальном протоколе ветвей, fine-tune real/sim и окончательная UI fault-матрица. Аппаратные калибровки идут только после A в порядке ROSMASTER → Tank → SO-101.

Снимки доступных первоисточников и контрольные суммы: runtime `cache/references/sim-training/manifest.json`. ReadTheDocs отказал отдельному offline-загрузчику HTTP403; страницы проверены через web tool, не помечены как скачанные. Статьи и сайт Playground кэшированы. Для работы приложения интернет не требуется.
