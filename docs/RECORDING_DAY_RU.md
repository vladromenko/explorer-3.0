# День записи Explorer 3.0

1. **Подготовьте одну платформу и сцену.** SO-101 стоит на столе; Tank и ROSMASTER — на полу. Для рук используйте одинаковые кубик и коробку, для баз — видимую цель и отмеченную зону остановки. Уберите посторонние предметы. Зарядник отсоединён, выключатель доступен.
2. **Откройте [«Готовность парка»](http://192.168.0.168:8030/recording/readiness).** Посмотрите допуск, батарею, свежесть/частоту потоков, часы и свободный диск. Красная строка содержит действие. Ниже 8 ГБ новая запись не начнётся. Неподключённые роботы не нужно включать ради проверки одной машины.
3. **Пройдите «Проверку “всё ездит”» выбранного робота.** «Начать измерение шага» только читает датчики. Движения выполняете вы в панели; затем подтверждаете наблюдаемый результат и нажимаете «Проверить и сохранить результат». FAIL можно повторить. Для Tank сначала подтвердите отсоединённый зарядник и снимите напряжение 10 секунд; панель откроется после этого шага. Для SO-101 явно возьмите устройства у :8020, для ROSMASTER не используйте :8090 одновременно.
4. **Откройте [«Сбор датасета»](http://192.168.0.168:8030/recording/collect).** Выберите задачу, оператора и опишите расстановку. «Новая серия» создаст имена сама. Для той же расстановки выберите повтор — это останется одна группа. Базы по умолчанию пишутся с глубиной/лидаром, руки — обычным профилем. Вариант внутри задачи не смешивается.
5. **Один показ — одна попытка, 3–120 секунд.** В панели «Начать показ» → дождаться готовности и роста кадров → выполнить задачу → «Успех» / «Неуспех» / «Прервать». F9/F10/F11 относятся к записи, пробел — STOP. После сохранения можно начинать следующий показ; сбрасывайте сцену только после остановки. Автоматическая проверка читает запись обратно. Жёлтая запись сохранена, но не используется для обучения до разбора.
6. **После каждой серии посмотрите 1–2 видео.** Ориентир — 10 действительно разных расстановок по 5 качественных успешных показов на задачу. Счётчик «до 50» учитывает прошедшие проверку записи. Новое имя не делает ту же сцену независимой.
7. **В конце — STOP, копия и выключение.** На «Готовности» нажмите «Сделать копию сейчас». Подключённый внешний диск должен иметь папку `explorer3-backup`, либо задайте путь. Без него сохраняются только локальный SQLite и манифест хешей, не вторая копия видео. При необходимости верните SO-101 кнопкой «Вернуть в :8020», Tank — приложению Hiwonder. Выключите робота перед зарядкой. **Tank заряжается выключенным, штатным зарядником** ([инструкция производителя, раздел 1.3](TANK.md)).

Обучение в день подготовки не запускается. После набора данных можно отдельно подготовить неизменяемый план обучения; запуск — следующий согласованный этап. Подробности: [датасет и обучение](DATASET_GUIDE_RU.md), [физические проверки](PHYSICAL_ACCEPTANCE_RU.md), [состояние пакетов](RECORDING_IMPLEMENTATION_STATUS.md).
