# Explorer 3.0 — оставшаяся физическая приёмка

Это список проверок, а не разрешение начать движения прямо сейчас. Включать
только проверяемую платформу. Зарядник перед движением отсоединён. Обучение
для этих проверок не нужно. Прежние принятые результаты сохранены; повторяется
только короткая проверка после обновления и новые тракты датчиков.

## 1. ROSMASTER

Открыть **http://192.168.0.168:8030/rosmaster/control**. Старую :8090 в это
время не запускать. После отдельного допуска:

1. На свободном участке коротко проверить вперёд/назад, влево/вправо и поворот.
   Отпускание останавливает; STOP останавливает; после нового явного включения
   управление снова работает. Скрытие вкладки останавливает без самовозобновления.
2. Без предмета проверить небольшое движение каждого сустава и полный рабочий
   ход захвата. Затем XYZ: отдельно вперёд/назад, влево/вправо, выше/ниже.
   Не проверять предельные положения силой.
3. Только при подключённом Leader: включить зеркало неподвижно, затем немного
   согнуть локоть и раскрыть/закрыть захват. Проверить направление, вход без
   неожиданного скачка и STOP. Для обычной клавиатурной записи Leader не нужен.
4. Открыть **/rosmaster/sensors**: при перемещении видимого предмета согласованно
   меняются RGB, глубина и сканы; затем короткая запись и её просмотр.
   По желанию один раз проверить 5-секундный микрофон и RGB-подсветку.
   OLED не включён в допуск: нет документированной команды текущего MCU.
5. Записать по одному короткому законченному показу **«Рука + глубина и лидары»**
   и **«База + глубина и лидары»**. После сохранения: движение видно,
   захват/шасси соответствуют командам, конец записи и исход верны, проверка
   данных проходит. Затем ещё два показа выбранной для основного набора задачи.
6. Остановить Explorer и проверить возврат прежнего управления.

## 2. Tank — сначала устранение независимой остановки

До обычных поездок нужно решить границу отказа: при потере USB моторная плата
должна сама прекратить движение либо независимый канал должен отключить тягу.
Одна программная команда STOP с Raspberry Pi этого не гарантирует. Пока
механизм не подтверждён, блокировка движения и датасета сохраняется.

После конкретного решения — отдельная стендовая проверка: устойчивое основание,
обе гусеницы свободны, зарядник отключён, оператор у выключателя. Сначала
короткое движение, отпускание и STOP; затем согласованная проверка исчезновения
команд и отказа канала. Не выдёргивать USB у движущегося робота самостоятельно.

После стендового допуска:

1. **http://192.168.0.168:8030 → Tank → Управление**: прямые направления,
   повороты и диагональные дуги; отпускание, STOP, новое включение, скрытие вкладки.
2. **/tank/sensors**: камера, глубина, ИК и лидар соответствуют сцене; Wi-Fi
   сохраняется без Ethernet, показание питания проверяется без зарядника.
3. Три отдельных коротких подъезда к видимой цели с остановкой в размеченной
   зоне, профиль **«Tank + глубина и лидар»**. После каждого сохранить и проверить
   запись. Вернуть штатное управление. Командная оценка движения не выдаётся
   за измеренную колёсную одометрию.

## 3. SO-101 на Homebrain

**http://192.168.0.168:8030 → SO-101**. Проверить короткое следование Leader,
захват, STOP и скрытие вкладки. Записать один кубик → коробка → отвести руку,
проверить видео/действия/исход, затем ещё два коротких показа. Вернуть управление
в старую :8020; её исходники и служба сохранены.

## 4. Общие наблюдения и агентная задача

После отдельных допусков включить только нужную пару. На **/fleet/live**
записать один общий видимый эпизод и проверить порядок событий при просмотре.
Для общей метрической сцены измерить высоту стола, положения камер/роботов
и согласованный ориентир; сейчас локальные облака не являются единой картой.

На **/team/observations** получить кадры, затем **/team/real** подготовить
конкретные уже проверенные испытания. Для физического агентного допуска нужны
принятые навыки и начальные условия — диагностический checkpoint не годится
как доказательство обученного поведения. Проверить отмену во время подключения,
STOP, сохранение исхода и отсутствие автоматического следующего движения.
Передачу кубика со стола напольному роботу этот стенд не обещает.

## Когда можно массово записывать

После пунктов управления/STOP и трёх пробных записей **данной задачи** можно
собирать её основной набор по [инструкции](DATASET_GUIDE_RU.md). Ждать обучения
или готовности всей команды для отдельного датасета не нужно. Tank требует
отдельного закрытия инцидента USB; проверка камер его не закрывает.

Отложенные по указанию оператора вызовы VLM, новые симуляционные прогоны R4/S2
и научные сравнения требуют отдельного разрешения запуска. Они не относятся
к физической проверке кнопок и не объявлены уже выполненными.
