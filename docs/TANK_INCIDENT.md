# Tank: отказ первой физической проверки

Пользователь сообщил о неконтролируемом движении после команды вперёд и неработающем STOP; остановил питание. Физическая приёмка FAIL. Последующий успешный HTTP /stop не является опровержением наблюдения пользователя.

Сервер получил STOP 2026-11-12 01:08:04.736 MSK и закрыл цикл 216 отсчётов. Агент ответил /stop 200 в 01:08:05.849. Байты UART этой teleop-сессии не сохранялись; измеренного подтверждения моторной остановки нет. Журналы обоих узлов сохранены локально. Предварительный тест с нулевыми командами подтверждал лишь программную реакцию, а не торможение едущего шасси. Проверка на полу была преждевременной.

Подтверждён дефект интеграции: частичный адаптер не выполнял штатный send_machine_type и полный запуск board node. Фактически используемый заводской SDK и его копия совпали по SHA256. Причинность всего инцидента, особенно отсутствия физического STOP, пока не доказана.

По запросу пользователя частичный адаптер заменён полной цепочкой из копий controller и ros_robot_controller. Сохраняются оригинальные конструкторы, инициализация типа моторов/существующего порога питания/offsets, ограничения, кинематика, ROS-доставка и SDK. Исходники хранятся вне Git, изменены только пути к скопированным конфигам. Никакого нового обучения/движений старого backend.

В новом слое только: lifecycle, private HTTP, контроль записи serial, журнал, локальная защёлка STOP/TTL. Перезапуск не вооружает. После нештатного завершения нельзя выводить физическую остановку из закрытия PID/порта. Аппаратное подтверждение MCU отсутствует.

Проверено на Tank без аппаратуры: настоящие скопированные ROS-узлы и HTTP обработчики с serial.Serial, заменённым памятью до инициализации. Отдельно STOP после ненулевого пакета и тайм-аут после ненулевого пакета: сформированы нули, следующая команда отвергнута. Полная начальная последовательность пакетов сохранена. 15 локальных тестов PASS. Эти результаты не дают физический PASS.

Защитные marker-файлы сохранены на Homebrain и Tank. Агент инертен, запуск сессии 409. Заводские службы после пользовательской перезагрузки активны; код прежнего управления не исправлялся.

Следующая физическая проверка возможна только после зарядки, без зарядного кабеля, на устойчивой подставке с обеими гусеницами в воздухе и доступным выключателем. До подтверждения такой подготовки запрет движения остаётся. Три показа/обучение и переход к ROSMASTER отложены до успешной проверки STOP и связи.
