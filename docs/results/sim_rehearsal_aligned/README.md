# Репетиция обучения на задачах MuJoCo, повторяющих блоки записи (15.11.2026)

Показы эксперта MuJoCo: SO-101 «передача» — 58, ROSMASTER «взять с пола» — 65; сильная рандомизация внешнего вида. Обучение через очередь Explorer по пилотным бюджетам (SmolVLA 5 000 шагов, ACT 8 000, batch 8), затем 20 новых сцен MuJoCo через исполнитель робота и «Допуск к роботу».

| Задача | Модель | Успех в MuJoCo | Допуск | Время расчёта |
|---|---|---|---|---|
| SO-101 передача | SmolVLA | 1/20 (5%) | не допущена | 0.76 с из 1.33 |
| SO-101 передача | ACT | 6/20 (30%) | не допущена | 0.04 с |
| ROSMASTER с пола | SmolVLA | 0/20 | не допущена | — |
| ROSMASTER с пола | ACT | 0/20 | не допущена | — |

Что это значит:
- **Конвейер работает целиком** на обеих руках и обеих моделях: сбор → обучение → проверка в MuJoCo через исполнитель робота → допуск. Входы и выходы всех четырёх моделей совпадают с роботами.
- **Пилотных бюджетов мало для этих задач.** ACT для ROSMASTER опускается к кубику (до 3 см) и закрывает захват, но промахивается на 2–3 см, и кубик выскальзывает. Ошибки в конвейере нет, модель недоучена. Основной рецепт — 40 000 шагов ACT и 20 000 SmolVLA, плюс настоящие показы.
- **Допуск не пропустил ни одну модель, и это правильно:** успех в MuJoCo ниже 50%. Для ROSMASTER ещё нет настоящих показов для проверки. Для SO-101 настоящие показы есть только старой задачи «в коробку», поэтому сравнение с ними не о том.
- SmolVLA укладывается во время расчёта с запасом (0.76 с из 1.33).
