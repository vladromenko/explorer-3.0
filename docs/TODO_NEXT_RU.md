## Необходимое участие владельца: только SO-101

2. Сохранить настройку геометрии и подготовить отдельную серию донорского захвата. Команда: взять кубик, поднять ≥5 см, удержать 2 с, вернуть на стол. Не обозначать это как передачу человеку или прежнюю полную задачу «в коробку».
3. Владелец выполняет три ручных показа через прежнее управление Leader/Follower; явно начинает/заканчивает каждый и отмечает исход. Ничего не запускается автоматически.
4. Затем проверить запись и фазовые границы. Для реального пакета отдельно нужны измеренные контактный TCP, метрическая кривая губок, задержка камеры и минимум три независимые контрольные точки/раскрытия, не использованные для подгонки. Неизвестные числа не выдумывать.

Сборщик: scripts/build_so101_skill_packet.py --episode ID --review PATH. Review должен ссылаться на реальные проверенные файлы/хеши. Синтетические тестовые фикстуры и старая nominal-калибровка не заменяют текущую проверку.
