# Explorer 3.0

Локальная система Homebrain для управления роботами, записи показов и подготовки проверяемых датасетов. Mac используется как браузер; исходные данные и вычисления остаются на Homebrain. Существующие :8020/WristLab и Console :8090 не переписываются.

**Открыть: http://192.168.0.168:8030**. Начните с [готовности парка](http://192.168.0.168:8030/recording/readiness), затем — физическая проверка и [сбор серий](http://192.168.0.168:8030/recording/collect). Короткая инструкция: **[День записи](docs/RECORDING_DAY_RU.md)**.

## Текущий объём

Подготовка R0–R9 по [заданию](docs/handoffs/RECORDING_READINESS_PROMPT_RU.md): единый `fleet.json`, локальные ограничения и восстановление Tank, запись ROSMASTER, явная передача SO-101, готовность, серии/проверка качества, резервные копии, физический мастер и инструкции. [Пакеты и свидетельства](docs/RECORDING_IMPLEMENTATION_STATUS.md), [актуальное состояние](CURRENT_STATUS.md), [история](STATE.md).

Старые постоянные блокировки Tank архивированы по решению пользователя; езда по полу допускается пользователем из интерфейса. USB-отказ завершает сеанс; восстановление не возобновляет движение. Подтверждение остановки и новое включение обязательны. Программные проверки не доказывают аппаратную остановку при обрыве связи: [Tank](docs/TANK.md), [история инцидента](docs/TANK_INCIDENT.md).

## Рабочий путь

1. Проверить готовность только нужной платформы; пройти её мастер «всё ездит». Открытие страницы не включает приводы.
2. Выбрать одну из четырёх задач: SO-101 pick/place, ROSMASTER pick/place, ROSMASTER dock, Tank dock. Для баз предлагается RGB-D/lidar/IMU, для рук — обычный профиль. Вариант фиксируется для задачи.
3. Создать серию; одна попытка — один эпизод. Сохранить исход, дождаться записи. Проверка чтения, временных пропусков и числовых полей автоматическая; оригиналы не удаляются.
4. Собрать примерно 10 независимых расстановок × 5 успешных качественных показов, просмотреть видео, сделать внешнюю копию. Общая серия **или** расстановка связывает эпизоды в одну группу, в том числе транзитивно.
5. После отдельного разрешения подготовить и запустить обучение. Наличие рецепта и успешный программный тест не означают обученного физического навыка. [Датасет и дальнейшее обучение](docs/DATASET_GUIDE_RU.md).

Tank сохраняет реальные RGB/depth/lidar/IMU и команды. Скорость колёс не измеряется: предыдущая команда, заводской `/odom_raw` и интеграл команды не выдаются за измеренную одометрию. Производные IMU/пары сканов имеют отдельные поля и ограничения. ROSMASTER пишет измерения энкодеров и суставов; пропуски не заменяются вымышленной позой.

## Запуск, тесты, хранение

```bash
cd ~/Projects/explorer-3.0
./start.sh
./scripts/run_all_tests.sh
./stop.sh
```

Собственная user-служба — `explorer3-ui.service`. Перезапуск инертный: управление и прерванные записи не возобновляются. Полные конфигурации, токены, калибровки, данные, веса, backup и журналы — в `~/.local/share/explorer3`, вне Git. Системные ROS/CUDA и старые окружения не обновляются. [Программные проверки](docs/SOFTWARE_TESTS_RU.md) выполняются в изолированных каталогах; вызовы моделей и обучение пропускаются явно.

Внутренние записи, подготовка обучения, агентные роли, общая ROS 2 шина наблюдений и симуляция сохранены. Контроллеры не заменены общей DDS-командой на все моторы. MuJoCo работает отдельно в `.venv-sim`; развитие автономности — следующий этап после датасета. [Модели](docs/SIM_MODELS.md), [переиспользование](docs/RESEARCH_REUSE.md), [системная передача](docs/SYSTEM_HANDOVER_RU.md).

## Питание и сеть

Homebrain работает от сети. Tank — MentorPi T1 с фактически установленной Raspberry Pi 5; доступ по домашнему Wi-Fi, провод не обязателен. При низком заряде сначала зарядить выключенным штатным зарядником. ROSMASTER и SO-101 включаются по очереди для нужного сценария. Настройки заводского AP, исходные проекты и прошивки сохранены.
