# Explorer 3.0

**По предложению пользователя программная подготовка ROSMASTER идёт, пока Tank заряжается.** Этап C остаётся незавершённым.

**Tank: движение заблокировано после физического отказа STOP.** Частичный SDK-адаптер заменён полной копией штатной цепочки; тесты без аппаратуры прошли. Физическая проверка исправления ещё не выполнена. До неё не запускать Tank на полу. Подробности — STATE.md и docs/TANK_INCIDENT.md.

Новый независимый проект на Homebrain (Jetson Orin NX 16 GB). Этапы A и B прошли приёмку; следующий этап C — только Tank. Прежнее управление SO-101 на :8020 восстановлено и проверено пользователем. Подробности — STATE.md.

Private repository: https://github.com/vladromenko/explorer-3.0

UI в доверенной LAN: http://192.168.0.168:8030. Локальный адрес: http://127.0.0.1:8030 (запуск и перезапуск проверены).
Доступ с Mac через существующий SSH: `ssh -N -L 8030:127.0.0.1:8030 jetsonnx@192.168.0.168`, затем открыть http://127.0.0.1:8030 на Mac.
Доступ разрешён только loopback и сети 192.168.0.0/24 с проверкой Origin; остальные HTTP/WebSocket соединения отвергаются. Mac только браузер/терминал; все вычисления и файлы на Homebrain.

Запуск: `./start.sh`. Остановка: `./stop.sh`. Отдельная user-служба `explorer3-ui.service`.
Повторный запуск/остановка идемпотентны. Открытие страницы и рестарт никогда не разрешают движение.
Установка службы: `./scripts/install_service.sh`. Автоматическое включение на загрузке пока не настроено.

Код в `~/Projects/explorer-3.0`. Локальные данные, веса, калибровки, SQLite и журналы в `~/.local/share/explorer3`, вне Git.
Старые базы/датасеты/checkpoints не используются. Зависимости закреплены; PyTorch/CUDA системы не изменяются.

Последовательность: A Homebrain → B SO-101 → C Tank → D ROSMASTER → E совместная приёмка → F сбор и исследование.
Tank и ROSMASTER для A не нужны. USB-подключение не равно проверке питания или разрешению движения.
Homebrain от сети; SO-101 от существующих подходящих блоков; машины от штатных батарей. Напряжения/источники не менять.
Неподтверждённый заряд отображается как неизвестный. Никаких придуманных процентов или одометрии.

LeRobot 0.6.1, upstream tag 7e241bd630a3719a56157a497ce5d08f244784f1. NiceGUI 3.19.0, Quasar и CSS локальные, без CDN.
Источники API: https://github.com/huggingface/lerobot/tree/v0.6.1 и https://nicegui.io/documentation/section_foundations.
Происхождение копий — docs/PROVENANCE.md. Научный протокол — docs/RESEARCH_PROTOCOL.md.

Непроверенные физические функции заблокированы. Software smoke использует отдельный synthetic fixture и не означает физический PASS.

Проверено offline: UI и локальные assets; 3 synthetic video episodes → ACT 50 steps → новый процесс reload/inference; SmolVLA forward/backward/save/reload и официальный trainer 1 step. 13 компактных тестов и pip check PASS. SO-101: три настоящих показа (2636 кадров, около 30 Hz), ACT 50 шагов batch 8 и новый процесс reload/inference PASS. Проверены плавная телеперация, STOP и остановка при скрытии вкладки без автоматического возобновления.

Просмотр настоящих эпизодов: вкладка «Датасеты» → выбрать эпизод → «Посмотреть»; видео и синхронные команды/измерения. Live preview использует отдельный HTTP MJPEG.

Ограничения: replay/rollout и длительное обучение с validation/resume ещё требуют доводки на следующих этапах; выключенные кнопки не означают реализованную функцию.

## Дальнейшие показы SO-101 — после отдельной карточки сбора

Сейчас три успешных пилотных показа сохранены; ждать массового сбора для перехода к Tank не нужно. Первый ориентир — 50 качественных показов всего (ещё 47, если три пилотных подходят), а не гарантия навыка.

1. Освободить руку в прежнем управлении: STOP. В Explorer «Управление» → «Explorer 3.0». Передача ресурсов сама движение не запускает.
2. «Запись» → «Начать показ», дождаться «Следование — можно двигать Leader». Взять кубик, положить в коробку, отвести руку, нажать «Закончить · успех». Если задача не выполнена — «неуспех»; проблемный эпизод не отмечать успехом.
3. Дождаться «Остановлено» и сохранения. Только тогда вручную вернуть кубик. Сброс сцены не записывать в показ; держать страницу видимой во время следования.
4. Собирать небольшими сериями с разными доступными положениями кубика и коробки, сохраняя цель в wrist-обзоре и оставаясь в проверенной рабочей зоне. Не менять калибровку или пределы суставов. Разные расстановки обозначать разными именами в поле «Расстановка».
5. Просматривать записи, исключать смазанные/неполные показы из обучения без удаления оригиналов. Перед полным обучением отдельно зафиксировать сессии/расстановки и split; его UI и validation/resume ещё не приняты.
6. В конце STOP → дождаться закрытия → «Прежнее управление». При пропаже видео/связи остановиться и проверить причину; повторный запуск только явной кнопкой.

Текущий checkpoint — только проверка train/save/reload. Автономный перенос кубика им ещё не проверялся; кнопки физического replay/rollout пока отключены.


## Tank: доступ по Wi-Fi

Tank подключён к той же домашней Wi-Fi сети, что Homebrain и Mac. Проверен SSH после физического отключения Ethernet. На Homebrain: `ssh hiwonder-tank`. На Mac: `ssh pi@raspberrypi.local` (его ключ уже установлен; фактический вход с Mac ещё не проверен). Текущий DHCP адрес: `192.168.0.136`; имя mDNS предпочтительнее адреса. Старый alias `hiwonder-tank` на Mac пока ведёт на Ethernet.

Проводной резерв: Tank `192.168.150.1`, Homebrain `192.168.150.3`, Mac `192.168.150.2`. На Homebrain: `ssh hiwonder-tank-wired`. Профиль Tank хранится в поддерживаемом [каталоге NetworkManager](https://networkmanager.dev/docs/api/latest/nm-settings-keyfile.html), который заводской Wi-Fi скрипт не очищает. Wi-Fi настроен штатным конфигурационным override, оригинальный скрипт и служба неизменны. Подготовлен возврат заводского AP `HW-9E015B81` через `/home/pi/explorer3/network/restore-factory-ap.sh`, только с подключённым Ethernet. Холодный старт с новым Wi-Fi ещё не проверен.


Подготовка управления Tank: в :8030 выбрать Tank; после разрешённого физического блока «Управление» → «Explorer 3.0» → «Проверить телеперацию». Стрелки/WASD и экранные кнопки работают при удержании; отпускание задаёт нули, пробел/STOP закрывает сессию. Потеря фокуса/вкладки останавливает Tank. До физической приёмки не считать эту последовательность проверенной на шасси. Запись tank_dock использует переднюю камеру и две команды v/omega; состояние честно обозначено предыдущей командой, измеренной одометрии нет.

Питание штатного MentorPi T1 по [Hiwonder](https://www.hiwonder.com/products/mentorpi-t1): 7.4 V, 2200 mAh. Explorer использует 6.9 V — порог уже установленного контроллера, не меняет плату/источник и не вычисляет проценты. Текущее напряжение отображается только при свежих данных. Изоляция, ограничения, возврат и ещё не выполненные проверки: docs/TANK.md. Программный старт агента проверен инертным; передача ресурсов, движение, три Tank-показа и возврат телефона ещё не проверены.
